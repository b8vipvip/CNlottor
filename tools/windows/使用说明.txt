CNlottor Windows v0.4 使用说明
================================

一、系统要求

1. Windows 10 或 Windows 11（64 位）。
2. 安装 Python 3.12、3.11 或 3.10，推荐 Python 3.12。
3. 首次启动需要联网下载服务端依赖和 PyTorch，下载量较大，请耐心等待。

二、首次启动

1. 完整解压本压缩包，不要直接在压缩软件中运行。
2. 右键 start_server.ps1，选择“使用 PowerShell 运行”。
3. 若系统阻止脚本，可打开 PowerShell，进入解压目录后执行：

   Set-ExecutionPolicy -Scope Process Bypass
   .\start_server.ps1

4. 脚本会自动：
   - 优先选择 Python 3.12，其次选择 3.11、3.10；
   - 创建 .venv 虚拟环境；
   - 安装 CNlottor 服务端、PyTorch 和分析依赖；
   - 创建 data 和 artifacts\models 目录；
   - 启动 http://127.0.0.1:8000 服务。

5. 看到“Uvicorn running”后不要关闭 PowerShell 窗口。
6. 双击 app\cnlottor_app.exe。
7. 客户端服务端地址保持为：

   http://127.0.0.1:8000

8. 点击“连接”。

三、客户端操作顺序

1. 选择彩票类型。
2. 点击“同步数据”。
3. 查看历史期数和最新期号。
4. 首次训练建议参数：训练轮数 3、历史窗口 12、隐藏层 32。
5. 点击“训练模型”。
6. 训练完成后点击“模型预测”。
7. 可继续执行频率分析、形态分析、规则挖掘、Copula 候选和滚动回测。

四、数据保存位置

数据库：data\cnlottor.db
模型：artifacts\models\<彩票代码>\latest.pt
虚拟环境：.venv

升级或重新解压客户端时，请先备份 data 和 artifacts 目录。

五、Android 客户端

Windows 服务默认监听局域网。Android 客户端需填写电脑的局域网地址，例如：

http://192.168.1.20:8000

请确保手机和电脑连接同一网络，并允许 Windows 防火墙中的 Python 网络访问。

六、常见问题

1. 提示找不到 Python：
   安装 Python 3.12，并确保安装了 Python Launcher 或已添加到 PATH。

2. 第一次启动长时间没有完成：
   通常是在下载 PyTorch，请保留窗口并等待。

3. 客户端连接失败：
   确认 PowerShell 服务端窗口仍在运行，并访问：
   http://127.0.0.1:8000/health

4. 模型预测提示未找到模型：
   先同步数据，再点击“训练模型”。

5. 7星彩旧模型不兼容：
   v0.4 已采用六位基本号码加特别号码的新结构，请重新训练 7星彩模型。
